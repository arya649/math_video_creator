# Example scripts

Complete scripts that work in the engine, one per sample project on the hosted site
(open `https://mathvideocreator.vercel.app/?project=<name>` to see each play).

| File | Shows | Files it needs beside it |
| --- | --- | --- |
| demo.json | board world, equation steps, two languages | none |
| graphs.json | graph world: plots, tangents, areas, values, plane transforms | none |
| geometry.json | geometry world: constructions, dragging, cutting and rearranging | none |
| counting.json | counting world: number lines, arrays, fractions, chance | none |
| space.json | space world: surfaces, nets, revolving, slicing; thumbnail, end screen | none |
| teaching.json | questions, answers, mistakes, cards, recap, charts, a picture | picture.png |
| wonders.json | Fourier circles, a Mandelbrot dive, π by darts | heart.svg |
| sound.json | own recording, music under the voice, the engine's sounds | my_recording.mp3, music.mp3 |
